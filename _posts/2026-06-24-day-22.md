what_i_learned: |
  This morning, we continued building our machine learning and data analysis skills by working through several hands-on exercises in Python. We started by setting up our coding environment and importing essential data science libraries such as NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
  
  We explored the fundamentals of NumPy by creating arrays, reshaping data into matrices, calculating statistics, and visualizing a sine wave. We then moved into Pandas, where we loaded the Breast Cancer dataset and learned how to inspect, summarize, and manipulate data. One interesting task involved creating a new categorical column that translated numerical target values into descriptive labels, making the data easier to understand.
  
  Next, we practiced data cleaning and feature engineering. We intentionally introduced missing values into the dataset and learned how to handle them using median imputation. We also created a new feature called area_perimeter_ratio, which demonstrated how new variables can be engineered from existing data to potentially improve model performance.
  
  We explored data visualization using Seaborn and created histograms to better understand how features differed between benign and malignant tumor cases. Finally, we trained and evaluated four machine learning models: Logistic Regression, k-Nearest Neighbors, Decision Tree, and Random Forest. It was interesting to compare their performance and see that Logistic Regression achieved the highest accuracy of approximately 98.2%.
  
  During the afternoon session, I presented my findings from the exploratory data analysis of my dataset. I explained what the various charts and visualizations revealed about the distribution of features and the overall structure of the data. Afterward, I spent the remainder of the day studying the environmental, demographic, and socioeconomic variables available in our dataset to determine which features are most relevant for predicting Chronic Heart Disease (CHD). This helped me better understand the relationship between environmental conditions and health outcomes.
  
blockers: |
  I did not encounter any major blockers today. The only challenge was sorting through a large number of potential variables and determining which features would be most meaningful for the CHD prediction model. This required careful review of the data dictionary and thoughtful consideration of how different environmental and socioeconomic factors may influence heart disease risk.
