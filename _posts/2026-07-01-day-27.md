what_i_learned: |
  Today I focused on understanding the relationships between the features in my dataset before beginning the machine learning modeling phase. I learned about Variance Inflation Factor (VIF) and how it helps detect multicollinearity, which occurs when multiple variables provide nearly the same information. I calculated the VIF scores for all my selected features and found that variables such as E_ASTHMA and E_SMOKE had extremely high VIF values, indicating that they share a large amount of information with other features. This showed me that some variables may need to be removed or combined to improve model performance and make the results easier to interpret.
  
  I also performed an absolute correlation analysis using a correlation threshold of 0.80 to identify highly related feature pairs. This analysis revealed strong relationships between variables such as E_MINRTY and E_AFAM, as well as E_MHLTH and E_ASTHMA. To visualize these relationships, I created a correlation heatmap that included both the predictor variables and my target variable, F_CHD. The heatmap helped me better understand how environmental, demographic, socioeconomic, and health-related factors interact and which variables are likely to contribute the most to predicting coronary heart disease risk.
  
blockers: |
  One challenge I encountered was deciding which highly correlated features should be removed and which should be retained. Although the statistical results clearly identified redundant variables, selecting the most meaningful features requires balancing statistical evidence with domain knowledge. I spent time reviewing the relationships between variables to ensure that important information would not be lost during feature selection.
  
reflection: |
  Today's work reminded me that building a successful machine learning model begins long before training an algorithm. Understanding the data, identifying redundancy, and selecting meaningful features are just as important as choosing the right model. I enjoyed seeing how statistical techniques like VIF and correlation analysis revealed hidden patterns within the dataset and helped explain why some variables carry similar information. Every step of this process is giving me a deeper appreciation for the importance of data preparation in machine learning. I am looking forward to selecting my final feature set and beginning the model training phase, where I will finally see how these decisions influence prediction performance.
